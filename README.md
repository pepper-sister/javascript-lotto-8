# javascript-lotto-precourse

## 기능 요구 사항

간단한 로또 발매기를 구현한다.

- 로또 번호의 숫자 범위는 1~45까지이다.
- 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
- 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
- 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
  - 1등: 6개 번호 일치 / 2,000,000,000원
  - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
  - 3등: 5개 번호 일치 / 1,500,000원
  - 4등: 4개 번호 일치 / 50,000원
  - 5등: 3개 번호 일치 / 5,000원
- 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
- 로또 1장의 가격은 1,000원이다.
- 당첨 번호와 보너스 번호를 입력받는다.
- 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다.
- 사용자가 잘못된 값을 입력할 경우 "[ERROR]"로 시작하는 메시지와 함께 Error를 발생시키고 해당 메시지를 출력한 다음 해당 지점부터 다시 입력을 받는다.

### 입출력 요구 사항

**입력**

- 로또 구입 금액을 입력 받는다. 구입 금액은 1,000원 단위로 입력 받으며 1,000원으로 나누어 떨어지지 않는 경우 예외 처리한다.
<pre>
    14000
</pre>

- 당첨 번호를 입력 받는다. 번호는 쉼표(,)를 기준으로 구분한다.
<pre>
    1,2,3,4,5,6
</pre>

- 보너스 번호를 입력 받는다.
<pre>
    7
</pre>

**출력**

- 발행한 로또 수량 및 번호를 출력한다. 로또 번호는 오름차순으로 정렬하여 보여준다.
<pre>
    8개를 구매했습니다.
    [8, 21, 23, 41, 42, 43] 
    [3, 5, 11, 16, 32, 38] 
    [7, 11, 16, 35, 36, 44] 
    [1, 8, 11, 31, 41, 42] 
    [13, 14, 16, 38, 42, 45] 
    [7, 11, 30, 40, 42, 43] 
    [2, 13, 22, 32, 38, 45] 
    [1, 3, 5, 14, 22, 45]
</pre>
- 당첨 내역을 출력한다.
<pre>
    3개 일치 (5,000원) - 1개
    4개 일치 (50,000원) - 0개
    5개 일치 (1,500,000원) - 0개
    5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
    6개 일치 (2,000,000,000원) - 0개
</pre>
- 수익률은 소수점 둘째 자리에서 반올림한다. (ex. 100.0%, 51.5%, 1,000,000.0%)
<pre>
    총 수익률은 62.5%입니다.
</pre>
- 예외 상황 시 에러 문구를 출력해야 한다. 단, 에러 문구는 "[ERROR]"로 시작해야 한다.
<pre>
    [ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
</pre>

**실행 결과 예시**

<pre>

    1,2,3,4,5,6
    
    보너스 번호를 입력해 주세요.
    7

## 구현할 기능 목록

- [x] 사용자 입력
  - 로또 구입 금액, 당첨 번호, 보너스 번호 입력
  - <code>@woowacourse/mission-utils</code>에서 제공하는 <code>Console API</code>의<code>Console.readLineAsync()</code>사용
- [x] 당첨 번호 구분
  - 쉼표(,)를 기준으로 구분
- [x] 발행된 로또 수량 출력
  - 사용자 구입 금액에 맞춰 로또 수량 출력
  - <code>@woowacourse/mission-utils</code>에서 제공하는 <code>Console API</code>의<code>Console.print()</code>사용
- [x] 발행된 로또 번호 출력
  - 사용자 로또 개수에 맞춰 로또 번호 출력
  - 1에서 45사이의 중복되지 않은 정수 6개
  - <code>@woowacourse/mission-utils</code>에서 제공하는 <code>Random API</code>의<code>Random.pickUniqueNumbersInRange(1, 45, 6)</code>사용
- [x] 발행된 로또 번호 오름차순 정렬
  - 반환된 6개의 번호를 오름차순으로 정렬
- [x] 당첨 내역 출력
  - 당첨 번호와 일치하는 로또 번호 개수 구하기
  - 5개 일치시, 보너스 볼과 일치 여부 확인
- [x] 수익률 구하기
  - 구입 금액과 획득 금액 비교로 수익률 구하기
  - 수익률은 소수점 둘째 자리에서 반올림
  - 소수점 한자리까지 출력
- [x] 로또 구입 금액 관련 Error 출력
  - 로또 구입 금액에 0원 이하를 입력한 경우 예외 처리
  - 로또 구입 금액이 1,000원으로 나누어떨어지지 않는 경우 예외 처리
- [x] 당첨 번호 관련 Error 출력
  - 당첨 번호가 1~45 사이의 정수가 아닌 경우 예외 처리
  - 당첨 번호에 중복된 정수가 있는 경우 예외 처리
    예외 처리
- [x] 보너스 번호 관련 Error 출력
  - 보너스 번호가 1~45 사이의 정수가 아닌 경우 예외 처리
  - 보너스 번호와 당첨 번호가 중복된 경우 예외 처리
- [x] Jest를 이용하여 테스트
  - 당첨 번호와 일치하는 로또 번호 개수 비교

## 배운 점

1. **에러 출력 후 반복 처리**
   - <code>while</code>과 <code>try-catch</code>구조를 활용하여 사용자가 잘못된 값을 입력한 경우, 에러를 출력하고 다시 입력 받는 반복 로직 구현
2. **객체와 배열 활용**
   - 상수는 대문자, 객체 내 변수는 소문자로 정의하여, 같은 스펠링의 key에 대해 <code>toUpperCase()</code>를 사용하여 효율적으로 접근
   - 한 자리 이상의 숫자 배열을 오름차순으로 정렬하는 방법 학습
3. **코드 가독성**
   - 사용되는 문자열이나 숫자를 상수로 선언하고 사용
   - 한 메서드가 한 가지 기능을 담당하도록 기능별로 함수 분리
4. **테스트 코드와 예외처리**
   - 클래스 내부의 <code>validate</code> 메서드를 활용하여 에러 예외 처리 및 테스트 코드 학습
